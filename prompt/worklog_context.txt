Vai trò: Bạn là kỹ sư nền tảng (platform/DevEx) chuyên thiết lập quy trình làm việc đa agent. Nhiệm vụ: dựng cho tôi một hệ thống context + WORKLOG dùng chung để tôi luân phiên nhiều công cụ AI coding trên cùng một repo mà không xung đột và không mất ngữ cảnh khi chuyển tool.

Bối cảnh dự án:

- Dự án research: mô hình AI phân loại đa lớp ung thư gan trên MRI 3D. Repo sẽ chứa: code tiền xử lý/huấn luyện (chạy trên Kaggle), một web app demo tự code full-stack (FastAPI backend serve model + frontend thuần, KHÔNG Streamlit/Gradio), cùng các HTML slide và report trình bày kết quả.
- Tôi làm một mình nhưng dùng luân phiên 4 công cụ: Claude (Claude Code), Google Antigravity, OpenAI Codex, Cursor.
- Yêu cầu chất lượng UI/UX cho web app + slide + report ở mức cao nhất → sẽ tích hợp Impeccable (github.com/pbakaus/impeccable): design skill đa harness, cài bằng npx impeccable install, chạy /impeccable init sinh PRODUCT.md + DESIGN.md, có các lệnh /impeccable shape|craft|critique|audit|polish|typeset|layout|animate và CLI npx impeccable detect.

Sự thật ràng buộc bạn phải tôn trọng:

- Mỗi tool đọc file ngữ cảnh khác nhau: Claude Code → CLAUDE.md; Codex → AGENTS.md; Cursor → .cursor/rules/* và AGENTS.md; Antigravity → AGENTS.md (+ hệ memory riêng). Nếu duy trì nhiều bản song song sẽ bị drift. Hãy thiết kế một single source of truth rồi các file tool-specific chỉ trỏ/nhúng về nó.
- Impeccable KHÔNG hỗ trợ Antigravity chính thức (chỉ Claude/Cursor/Codex trong số tool của tôi có /impeccable). Phải đưa cách xử lý riêng cho Antigravity: đọc DESIGN.md/PRODUCT.md chung + chạy npx impeccable detect thủ công như quality gate.

Yêu cầu — tạo ra các artifact cụ thể theo thứ tự:

1. Kiến trúc file ngữ cảnh (single source of truth). Đề xuất chọn một file gốc (khuyến nghị AGENTS.md vì nhiều tool hội tụ về chuẩn này) chứa toàn bộ context dự án: mục tiêu, cấu trúc thư mục, tech stack, lệnh chạy, ràng buộc Kaggle, quy ước code. Rồi chỉ rõ cách để CLAUDE.md và .cursor/rules trỏ về file gốc (nhúng/import 1 dòng) thay vì sao chép nội dung. Viết đầy đủ nội dung AGENTS.md mẫu cho dự án này.
2. WORKLOG.md — nhật ký bàn giao giữa các tool. Thiết kế format chuẩn, append-only, để mỗi phiên làm việc (bất kể tool nào) ghi lại: timestamp, tool đang dùng, mục tiêu phiên, file đã đụng, quyết định/lý do, việc còn dang dở, và "điểm vào" cho phiên sau. Mục tiêu: mở tool bất kỳ, đọc entry cuối là biết tiếp tục từ đâu. Viết template + 1–2 entry ví dụ + quy tắc bắt buộc ghi khi nào.
3. Giao thức chống xung đột (handoff protocol). Quy tắc rõ ràng: chỉ một tool "cầm lái" tại một thời điểm; luôn git pull/commit sạch trước khi đổi tool; ai được sửa file config của tool nào; branch/commit convention; và checklist "trước khi rời tool" + "khi vào tool mới". Nêu các điểm dễ conflict thật sự (mỗi tool tự ghi đè file cấu hình của nó, lockfile, file Impeccable ephemeral) và cách phòng.
4. Tích hợp Impeccable cho 3 loại deliverable. Chỉ rõ: cài đặt (npx impeccable install --providers=claude,codex,cursor), /impeccable init để sinh PRODUCT.md/DESIGN.md phù hợp dự án y tế (giọng nghiêm túc, không màu mè, ưu tiên rõ ràng lâm sàng), và khi nào dùng lệnh nào trong vòng đời: shape→craft khi dựng web app UI, critique/audit/polish trước khi chốt, typeset/layout cho HTML slide và report. Ghi rõ những file Impeccable nào cần commit (config.json, design.json, critique/*.md) và block .gitignore cần thêm cho file ephemeral.
5. Xử lý riêng cho Antigravity. Vì không có /impeccable: hướng dẫn để Antigravity đọc DESIGN.md/PRODUCT.md như ràng buộc thiết kế qua AGENTS.md, và tích hợp npx impeccable detect src/ --json vào một script/pre-commit hook làm quality gate chung cho mọi tool (kể cả Antigravity), để đầu ra UI của mọi tool đều bị soi bởi cùng bộ 46 rule.
6. .gitignore + cấu trúc thư mục cuối cùng. Trình bày cây thư mục repo hoàn chỉnh (code Kaggle, web app, slides, reports, các file context, .impeccable/) và .gitignore gộp đủ cho cả 4 tool + Impeccable.

Nguyên tắc:

- Ưu tiên đơn giản và ít file trùng lặp. Một nguồn sự thật, phần còn lại trỏ về.
- Mọi quy tắc phải thực thi được (có lệnh git/script cụ thể), không chung chung.
- Thành thật: nếu hai tool xung đột không thể tránh hoàn toàn ở một điểm nào đó, nói rõ và đưa cách giảm thiểu thay vì giả vờ hoàn hảo.
- Kết quả cuối: xuất toàn bộ thành các file thực tế (AGENTS.md, CLAUDE.md, WORKLOG.md, .gitignore, và một docs/MULTI_TOOL_WORKFLOW.md mô tả giao thức) để tôi tải về và bỏ thẳng vào repo.

Bắt đầu bằng mục 1–2 (kiến trúc context + WORKLOG) và dừng lại cho tôi xem trước khi sang phần giao thức và Impeccable, vì đây là nền móng — sai chỗ này thì mọi thứ sau lệch theo.
